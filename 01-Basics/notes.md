## Class & Object
- Class is the blueprints for creating objects.

- **Example :** 
    - A company builds their own products. Before they start building actual product, at first they create the product's blueprint or pre-architecture which is used to build the multiple same products.

    - Here pre-architecture is called **Class**.
    
    - Multiple products are called **objects**.

    - Same as we create a class blueprint in program for a specific task. After creating the blueprint then we start building the actual tools.

    - After creating classes / blueprints we create multiple objects.

- **Creating class & Objects :**
```python

# Blueprint
class Product:
    name = "A"

# Objects
obj_1 = Product()
obj_2 = Product()
```

